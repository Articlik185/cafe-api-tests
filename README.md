**Тестирование HTTP API поиска кафе**

Учебный проект на Go по тестированию обработчика HTTP. Исходный сервер предоставлен в рамках курса Яндекс Практикума.

**Где смотреть решение**

[Ветка dev](https://github.com/Articlik185/cafe-api-tests/tree/dev) содержит дополнительные тесты количества результатов и поиска. [Учебный PR №1](https://github.com/Articlik185/cafe-api-tests/pull/1) сохранён открытым. В main находится исходная версия задания.

**Возможности API**

- GET /cafe с обязательным параметром city: moscow или tula.
- count ограничивает количество результатов, значение по умолчанию — 25.
- search фильтрует названия по подстроке без учёта регистра.
- Ответ — названия через запятую, не JSON.

**Запуск решения**

Требуется Go 1.24.1 или новее. В корне клонированного репозитория:

    git switch dev
    go test -v ./...
    go run .

Пример запроса после запуска:

    curl "http://localhost:8080/cafe?city=moscow&count=2"

Стек: Go, net/http, httptest, testify. Проверки включают HTTP-статусы, ошибки параметров, количество результатов и соответствие поисковой строке. Известное ограничение исходного сервера: отрицательный count не валидируется.
